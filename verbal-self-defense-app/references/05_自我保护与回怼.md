# 自我保护与回怼

> 本篇整理了被语言攻击、遭遇不尊重时的应对话术，学会高情商怼回去。

---

## 一、被语言攻击的高情商回怼

### 13条强硬回怼话术

1. 你这么说有意思吗？
2. 嘴笨这么臭，没刷牙吗？
3. 不了解情况就别乱说！
4. 我说话从来不带刺，如果今天让你难受了，我故意的。
5. 上帝真的公平，给了你一个好的外表，却给你一个低劣的人品。
6. 我脾气好不代表我没脾气。
7. 你是不是觉得欺负人很有成就感？
8. 你可以不喜欢我，但你没资格不尊重我。
9. 我给你脸了是吧？
10. 话不会说可以不说，没人当你是哑巴。
11. 你这话说出来自己信吗？
12. 你是不是对所有人都这么没礼貌，还是只对我？
13. 我尊重你是因为我有教养，不是因为你值得。

## 二、应对不尊重你的人

### 常见尴尬场景的高情商回怼

| 被说的话 | 高情商回复 |
|---------|-----------|
| 说你脑子有问题 | "我脑子有没有问题不知道，但你嘴巴有问题" |
| 说你有毛病 | "你才有毛病，我没空和你比" |
| 说你笨 | "我不笨，只是懒得和你计较" |
| 叫你滚 | "滚就滚，反正你不是我的方向" |
| 问你在吗 | "不在，我去了更好的地方" |
| 问你吃饭了吗 | "吃了，吃的闭门羹" |
| 问你工资多少 | "够活的，不够借你" |
| 被借钱 | "我也正想找人借呢，咱俩想到一块去了" |

### 被骂时的神回复

| 被骂的话 | 神回复 |
|---------|--------|
| 被骂傻B | "我是傻B，那你连傻B都不如" |
| 被骂真贱 | "那你是真的贵了" |
| 说你生气了 | "没生气，在给你留面子" |
| 骂你狗叫 | "汪汪汪，你听得真认真" |
| 说你逼逼啥 | "我在给你免费上课呢" |
| 说你急了 | "我不急，我只是在认真地告诉你闭嘴" |

## 三、职场中的自我保护

### 同事大庭广众之下捧杀你
- 不要顺着杆子爬，要谦虚但坚定
- "这主要还是团队的功劳，我只是做了分内的事"

### 同事在领导面前阴阳你不配合
- 用事实说话，不当场情绪化
- "感谢XX的反馈，我来补充一下完整的情况……"
