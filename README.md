# 3rd Career Exploration

> 霎哈嘉+X · 十二维评估矩阵

对陈家禾的「第三职业」各选项的深度评估，基于12个维度对10个项目进行五星评分。

## 评估维度

1. **教义合规** — 不碰霎哈嘉知识红线
2. **你想做** — 内心真正想投入的意愿
3. **配合静坐** — 是否利于修行状态
4. **轻脑子·闭环** — 不费大脑，有始有终
5. **不消耗** — 做了不累
6. **与人互动** — 需要真人交流
7. **能去爱** — 在工作中打开心、爱人
8. **利己成长** — 对灵性进步有帮助
9. **直接收钱** — 干活就有钱
10. **身体轻松** — 身体负担小
11. **时间自由** — 想干就干
12. **马上启动** — 门槛低
